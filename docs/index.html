Your PC's vital signs, in the corner of your screen.

DashStats is a small widget that shows what you care about: temperatures, load, frame rate, network health. It updates once a second, tells you in plain words when something's off, and stays out of your way.

It tells you what's wrong, in words.

A red number makes you guess. The header says what's going on. For network trouble it pings both your router and the internet, so it can tell a weak Wi-Fi from a bad internet provider.

On the desktop, or over your game.

Everything it can measure.

CPU
load, temperature, clock speed, power, busiest core
GPU
load, temperature and hotspot, clocks, VRAM, power, fan, video encoder. NVIDIA, AMD and Intel.
FPS
for the app in front: frame rate, 1% lows, frame time, stutters. Any game, any graphics card.
Network
speeds, ping, jitter, packet loss, router ping, retransmits, a log of hiccups, connections and open ports
Memory
RAM and committed memory
Storage
drive temperature, how full it is, read and write speed
Battery
charge, charge rate, time left, wear. Laptops only; desktops skip it.
System
uptime, total power draw, and DashStats' own CPU and memory, so you can see it isn't slowing you down

Install in a minute.

  1. Download DashStats.exe from the latest release.
  2. Double-click it and click Yes when Windows asks. It needs admin rights to read temperatures and frame rates.
  3. Click Yes to set it up, pick your uses and a look, and you're done. It starts with Windows from then on.

If Windows says "Windows protected your PC", click More info, then Run anyway. New apps from independent developers get that warning until they build a reputation.

Questions.

Is it free?

Yes, completely, and open source. No Pro version, no account, no ads.

Why does it need admin rights?

Windows only lets programs running as administrator read CPU temperatures and game frame rates. DashStats installs to Program Files, where other programs can't tamper with it.

Will it slow down my games?

No. It uses about half a percent of your CPU and draws itself without the graphics card. It even shows its own usage.

Does it work with my graphics card?

NVIDIA, AMD and Intel, including laptops with two GPUs.

Where does FPS come from?

Intel's open-source PresentMon, which reads frame timing straight from Windows. Works with any game.

Can I make it see-through over games?

Yes. Pin it with Ctrl+Alt+M, then pick a transparency from the tray icon, from solid to numbers only.

Privacy

DashStats doesn't collect, store or send anything about you or your PC. Its only network traffic:

  • a ping to 1.1.1.1 and your router once a second, to measure your connection
  • an update check to GitHub every few hours (turn it off from the tray icon)
  • the update download, only after you click Update now

Code signing policy

Releases are built from the public source on GitHub Actions and approved by hand before signing. Only this project's own binaries are signed.
