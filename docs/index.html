A tiny health check that lives in the corner of your screen.

Hi. I'm James and I made DashStats because every PC monitor I tried was either a wall of numbers or a gaming overlay that only cared about FPS. This one shows what you asked for, once a second, and stays out of your way. It's free, it's open source, and it's yours if you want it.

Download for Windows Source one .exe, that's the whole app

Windows 10 or 11, 64-bit. Nothing else to install.

It asks one question, then builds itself

The first time you run it: What do you use this PC for? Tick everything that applies and pick your main focus. Your main focus gets the big numbers; everything else shows smaller.

Light, and it minds its own business

0.1–1% CPU ~100 MB memory 0 GPU use measured on my laptop

It draws itself without the graphics card, so it never wakes a sleeping laptop GPU. Everything stays on your PC: no account, no telemetry, no ads. The only network traffic it creates is a tiny once-a-second ping to measure your connection. And it's open source, so you can read the code, change it, or make your own look.

Install

  1. Download DashStats.exe. Latest release.
  2. Double-click it and click Yes when Windows asks for permission. It needs admin rights to read temperatures and frame rates.
  3. Click Yes to set it up, pick your uses and a look, and click Start monitoring. It starts with Windows from now on.

Right-click the tray icon (near the clock) for everything else, including Uninstall.

Questions

Is it free?

Yes, completely. It's open source. If it's useful to you, you can buy me a beer.

Why does it need administrator permission?

Reading CPU temperatures and game frame rates requires low-level access that Windows only gives to programs running as administrator. DashStats uses well-known open-source components for this (see the credits at the bottom).

Windows says "Windows protected your PC" or blocks it.

New apps from independent developers can trigger Windows SmartScreen or Smart App Control until they build up a reputation or are code-signed. Click More info, then Run anyway.

If it won't start at all, check Windows Security → App & browser control → Smart App Control, which may be blocking it.

Will it slow down my games?

No. It updates once a second and uses around 0.1–1% of your CPU. It even shows you its own usage.

Does it work with my GPU?

NVIDIA, AMD and Intel GPUs are supported, including laptops with two GPUs.

Where does FPS come from?

From Intel's open-source PresentMon, which reads frame timing straight from Windows. It works with any game and any graphics card.

Can I change how it looks?

Yes. Pick one of four looks at any time with the EDIT button. Because it's open source, you can also build your own; easier theme-making is on the list below.

Will Windows updates break it?

It's built on actively maintained open-source projects. Occasionally a new Windows version or brand-new hardware needs an update, and those ship as new releases.
