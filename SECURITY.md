# Security

DashStats runs as administrator and installs a sensor driver, so security reports are taken seriously.

## Reporting a vulnerability

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/Varazi/dash-stats/security/advisories/new), not in a public issue. Include what you found, how to reproduce it, and the DashStats version.

You'll get a reply as soon as possible. Fixes ship as a new release, which installed copies are offered through the built-in updater.

## Supported versions

Only the latest release gets security fixes.
